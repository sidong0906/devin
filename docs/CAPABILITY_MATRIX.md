# Capability matrix: Power Apps capability vs. this repository

Status vocabulary: **enforced** (code path exists and a test fails if it regresses), **stub** (works locally, swap point marked, not production), **not built** (deliberate), **not replicable** (Devin should not try). "Tested by" names real test cases in this repo; grep them before quoting.
